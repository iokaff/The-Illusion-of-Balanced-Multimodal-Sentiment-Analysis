> 🚧 **Repository status:** Work in progress. Core experimental code, additional documentation and reproducibility materials are being organized and will be released soon.

## Overview

Can balanced optimization guarantee balanced multimodal learning?

This repository accompanies our investigation of **modality imbalance in multimodal sentiment analysis** and the limitations of optimization-based methods designed to balance modality contributions.
